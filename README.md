# 🎂 Happy Birthday, Gun Gun!

A birthday surprise website for Gun Gun — made from the
[Harmann60/Happy-Birthday](https://github.com/Harmann60/Happy-Birthday)
template, rebuilt with her own photos from Instagram.

- **Birthday:** 27 January (she turns 18 on 27 January 2027)
- **Hero:** her red-saree reel plays in the background
- **Photos:** 12 of her best moments — denim selfie, blue saree,
  pink kurta, teal kurta, festival glow and more
- **Live age counter:** counts up from 27 January 2009

## How to put it on your GitHub (GMC-Developer)

1. Create a new repository on GitHub, e.g. `gun-gun-birthday`
   (do **not** initialise it with a README).
2. Upload all the files in this folder to that repository
   (`index.html`, `style.css`, `script.js` and the `img/` folder).
3. Go to the repository **Settings → Pages**, set Source to
   **Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
4. After a minute the site will be live at
   `https://gmc-developer.github.io/gun-gun-birthday/`
